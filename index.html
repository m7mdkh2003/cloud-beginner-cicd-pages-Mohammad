What is CI/CD?

CI/CD stands for Continuous Integration and Continuous Deployment. It is a method used in cloud systems to automate building, testing, and deploying applications. CI ensures code changes are checked automatically. CD makes sure updates are deployed quickly and safely to production.

My Pipeline

When I push code to the main branch, GitHub Actions automatically runs a workflow. It checks that required files exist, then deploys the website to GitHub Pages. The site updates automatically without manual steps.
